## 1. Resumo da Solução

Desenvolvimento de um **site de portfólio profissional responsivo** que funciona como cartão de visita digital e hub de autoridade. O site mesclará:

- ✅ **Galeria de projetos** (acadêmicos + interiores) com renders, plantas e conceito técnico
- ✅ **Hub de artigos e TCC** com estrutura pronta para crescimento
- ✅ **Seção sobre** com credenciais e posicionamento
- ✅ **Contato direto** via WhatsApp/e-mail
- ✅ **Otimização para SEO** e redes sociais

**Stack:** Next.js (App Router) + TypeScript + Tailwind CSS + Vercel

## 2. Escopo da Proposta — Versão 1.0

### ✅ Incluído

#### A. Design & Direção Visual
- Análise de referência (arquitetojoaogabriel.com)
- Definição de tipografia minimalista + paleta de cores
- Wireframes de desktop e mobile (Home, Projeto, Artigo)
- Design System básico (componentes reutilizáveis)

#### B. Desenvolvimento
- Projeto Next.js com TypeScript (App Router)
- Páginas responsivas:
  - Home (com destaque de projetos + artigos)
  - Projetos (lista com filtro + detalhe individual)
  - Artigos (lista + detalhe com suporte a PDF)
  - Sobre (com foto + credenciais)
  - Contato (WhatsApp + e-mail público)
- Otimização de imagens (`next/image`, AVIF/WebP, lazy-load)
- Estrutura MDX para conteúdo no repositório

#### C. SEO & Performance
- Metadata dinâmica (Open Graph, Twitter Card)
- `sitemap.xml` + `robots.txt`
- Dados estruturados (Person, Article, CreativeWork)
- Lighthouse ≥ 90 em Performance/SEO/Acessibilidade
- Velocidade de carregamento otimizada

#### D. Hospedagem & Deploy
- Deploy na Vercel (preview + produção)
- Preview URL para testes antes de lançamento
- GitHub repositório público (versionamento)
- Configuração de domínio próprio no Vercel

#### E. Documentação & Entrega
- README com instruções de atualização
- Guia de como adicionar novos projetos
- Histórico de deploy e versionamento git
- Treinamento básico (via e-mail ou vídeo)
